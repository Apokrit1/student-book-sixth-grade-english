How Git Checkpoints Work

A Git Tag is like an unalterable bookmark attached to an exact moment in your project history. You can travel freely back and forth across these bookmarks without losing any work.

1. How to Travel to a Past Version

Click "Jump to Version" on any card to copy the command, then paste it in your terminal:

git checkout <tag-name>

Your files will instantly transform into that version. You can open portal.html or unit1/index.html in your browser to inspect or test it.

2. How to Return to the Present (Latest Code)

Whenever you are done exploring the past and want to return to today's code:

git checkout main

3. How to Make Experimental Changes to a Past Version

If you want to start modifying or testing ideas from an older checkpoint without messing up your main code, create a new branch from that tag:

git checkout -b my-experiment <tag-name>

4. Adding Future Checkpoints

Whenever you complete a new feature or unit and want to bookmark it, run this script to create a tag and update this dashboard:

python _tools/update_version_navigator.py
