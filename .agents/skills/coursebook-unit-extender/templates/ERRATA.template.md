# Unit <N> Errata

What the printed books get wrong for this unit, and how the app handles each item. The teacher decides every resolution.

Books: **SB** = Pupil's Book, **WB** = Workbook, **TB** = Teacher's Book. Page = printed page (PDF page in brackets). Source file = the file in `unit<N>/source/` where the text appears.

| ID | Book, page | Source file | Book says | Problem | Resolution | Pupil annotation ("Book check") | Status |
|---|---|---|---|---|---|---|---|
| E1 | SB p.xx (PDF p.xx) | `10_SB_unit.txt` | "…" | typo / fact / caption / impossible figure / contradiction / dated / unsuitable | keep / annotate / teacher-note / replace | "Your book says … In fact …" | pending |

## Resolutions

- **keep**: leave as printed, no note.
- **annotate**: pupil-visible "Book check" beside the item, plus a teacher note.
- **teacher-note**: teacher notes only; pupils see the book's version.
- **replace**: the app changes the text. Needs the teacher's explicit approval.

## Status

- **pending**: found, not yet decided. The app shows the book's version unchanged.
- **approved**: the teacher chose the resolution; the app implements it.
