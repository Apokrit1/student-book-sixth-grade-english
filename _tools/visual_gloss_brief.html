Visual Gloss Brief

Takes a vocabulary list, adds the settings, and writes the prompt an agent needs to fetch freely licensed pictures from Wikimedia Commons: one query per item, the licence policy, the attribution fields to keep, and the checks it must pass before anything ships.

Word list —

One item per line: id | word | search hint. The id and hint are optional, so a bare word works. Write the hint the way Commons titles files, one to three keywords (pumpjack, not an oil well pump in a field): every word must match, so a described scene returns nothing. Where the definition names a place, put that place in the hint. A pasted JSON array of {"id","word"} objects is detected automatically.

Named things ahead. — a real photograph of a named place is fine here, unlike a generated one, but the brief will tell the agent to confirm the file actually depicts it and to keep the photographer’s credit.
